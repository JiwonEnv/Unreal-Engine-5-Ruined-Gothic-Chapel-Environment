# UE5 Ruined Gothic Chapel Environment

> 서쪽부터 무너져 내린 13–14세기 영국계 고딕 석조 예배당. 남아 있는 구조와 재질의 시간감이 동쪽 제단으로 시선을 이끈다.

## 프로젝트 개요

Unreal Engine 5 환경 아트 개인 프로젝트입니다. 모듈러 건축, Hero Asset, 구조적 파손, PBR 재질, 라이팅, 최종 장면 연출까지 하나의 완성된 환경 제작 파이프라인을 구현하는 것을 목표로 합니다.

이 씬은 한때 피난처로 사용되었다가 방치된 소규모 예배당을 다룹니다. 소품은 건물의 이야기를 보조하는 수준으로 제한하고, 남은 건축 구조·재질의 노후화·붕괴 양상 자체가 공간의 서사를 전달하도록 설계했습니다.

## 공간 구성

* **서쪽 / 제1 Bay:** 출입구와 지붕을 중심으로 심하게 붕괴된 영역
* **중앙 / 제2 Bay:** 보존 영역과 붕괴 영역을 연결하는 부분 파손 구간
* **동쪽 / 제3 Bay:** 제단을 포함해 대부분 보존된 시각적 도착점

이 씬의 핵심 구조 규칙은 다음과 같습니다.

> 내부 벽부 기둥 = 리브 볼트의 시작점 = 외부 버트레스

세 요소를 같은 Bay 경계 축에 정렬해, 파손이 랜덤한 장식이 아니라 실제 구조가 무너진 결과로 보이도록 설계합니다.

## 아트 디렉션

* 첨두아치, 랜싯 창, 리브 볼트, 벽부 기둥, 버트레스를 고딕 건축 언어의 기준으로 사용합니다.
* 붕괴는 서쪽에서 동쪽으로 진행되며, 균등하게 흩뿌리지 않고 방향성과 구조적 원인을 갖게 합니다.
* 석회암의 마모, 젖은 면, 누수, 이끼, 먼지로 세월과 방치 상태를 표현합니다.
* 피난 흔적 소품은 제단과 건축 실루엣보다 먼저 읽히지 않도록 제한합니다.

## 재질 제작 기준

* Base Color, Normal, ORM 출력 규칙을 통일한 PBR 재질을 제작합니다.
* 석회암의 **Metalness는 0**으로 유지합니다.
* 마른 면과 젖은 면은 주로 Roughness 차이로 구분합니다.
* 반복 모듈은 공통 Texel Density를 사용하고, Hero Asset에만 고유 텍스처 해상도를 우선 적용합니다.
* Tiling, Trim, Unique Texture의 역할을 분리하고 프로젝트 전체에 동일한 ORM 채널 패킹 규칙을 사용합니다.
