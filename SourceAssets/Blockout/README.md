## 규격과 좌표

단위 cm. 서쪽 X=0 → 동쪽 X=1200, 내부 Y=-300~300, 바닥 상면 Z=20입니다.

|항목|규격|
|---|---|
|내부 / Bay|600×1200 / 길이400×폭600|
|벽 두께 / 측벽 높이|60 / 바닥 기준550|
|기둥·리브·버트레스 축|X=0,400,800,1200|
|리브 시작 / 볼트 정점|바닥 기준420 / 720|
|지붕 마루|바닥 기준850|
|측창 / 출입구 / 동쪽 창|100×280 / 160×320 / 240×400|
|제단 상판 폭|305|
|크기 비교 인물|180|

서쪽 Bay는 지붕과 볼트가 소실된 붕괴 구간, 중앙은 부분 파손, 동쪽은 보존 구간으로 배치했습니다. 측랑·독립 기둥·플라잉 버트레스는 만들지 않았습니다.

노션에 수치가 없는 창대 높이, 제단 깊이와 높이, 소품 위치·수량, 파손 윤곽, 검수 카메라는 블록아웃용 제안값입니다. 측창 창대160, 동쪽 창대220을 적용했습니다. 지붕 경사면 약3.8m라는 자료값은 폭6m와 마루/처마 높이차3m에 동시에 맞지 않으므로 전체 폭·높이를 우선했습니다. 지붕은 처마를 포함해 반폭375, 상승300의 임시 매스입니다.

## 검수와 범위

- 실제 액터 바운드에서 바닥, 측벽, 끝벽 방향과 치수를 확인했습니다.
- 입구 3경로, 내부 통로 3경로를 반지름25·반높이88 캡슐로 검사하여 장애물 충돌이 없음을 확인했습니다. 입구는 Y=-45,0,45, 내부는 Y=-65,0,65. 내부 검사는 제단 계단 앞 X=820까지입니다.
- 이 검사는 에디터 충돌 쿼리이며 전체 3인칭 PIE 플레이 테스트는 아닙니다.
- `verification.json`에 검사 결과, `build_report.json`에 생성 내역을 저장했습니다.
- `Blockout_Interior.png`, `Blockout_Exterior.png`는 실제 에디터에서 저장한 미리보기입니다.
- UV·노멀맵·최종 파손 디테일·PBR·VFX·Nanite 최적화는 후속 제작 범위입니다. 창 유리는 단색 불투명 자리표시자입니다.
- OBJ 임포트 시 스무딩/탄젠트 경고가 발생하여 블록아웃 메시의 법선·탄젠트를 재계산하고 MikkTSpace를 해제했습니다. 최종 텍스처용 UV는 별도로 제작해야 합니다.
